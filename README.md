# SOS Triage App

AI-powered first medical intake for travelers abroad. Built as part of the AI-101 Builder Studio course.

## Problem

Travelers who need urgent medical help abroad currently face long wait times (personal experience: ~1.5 hours before initial contact, ~15 hours before receiving medical advice) because every call starts with the same time-consuming manual intake process.

## What this project does

This platform aims to automate and speed up the initial medical intake for travel insurance emergency lines, reducing wait times for both travelers and medical staff.

## Tech Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Supabase (database)
- Vercel (hosting/deployment)
- GitHub (version control)

## Getting Started

1. Clone this repository
2. Install dependencies: `npm install`
3. Create a `.env.local` file with the following variables:

NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_key

4. Run the development server: `npm run dev`
5. Open [http://localhost:3000](http://localhost:3000)
